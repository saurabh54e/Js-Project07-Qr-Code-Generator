# JavaScript QR Code Generator

Project 7 of my 30 JavaScript Projects Challenge.

A clean and interactive QR Code Generator built using HTML, CSS, and Vanilla JavaScript that converts text or URLs into QR codes with download functionality.

---

## Features

- Generate QR codes from text or URLs
- Download QR codes as images
- Input validation with error feedback
- Responsive design for mobile and desktop
- Smooth UI interactions
- Dark mode support with theme persistence

---

## Architecture Approach

The application uses API integration and dynamic DOM manipulation to generate and display QR codes.

- Users enter text or a URL into the input field
- JavaScript validates the input before processing
- The QR Code API generates a QR code from the provided content
- The generated QR code is displayed dynamically in the interface
- Users can download the generated QR code as an image
- Theme preferences are maintained using Local Storage

---

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- QR Code API (api.qrserver.com)
- Local Storage API
